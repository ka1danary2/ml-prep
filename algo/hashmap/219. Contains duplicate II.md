Адекватное решение через set но не самое эффективное 
```
class Solution:
    def containsNearbyDuplicate(self, nums: List[int], k: int) -> bool:

         s = set()
         for i in range(len(nums)):
              if nums[i] in s:
                   return True
              s.add(nums[i])

              if len(s) > k:
                   s.remove(nums[i - k])

         return False
                        
                   
```

Главная проблема - если число не сошлось с одной парой, то не факт что оно не сойдется с другой, это надо учитывать

Составляем хешмап (словарь), где ключ - это значение, а значение - это индекс элемента

[1, 0]
[2, 1]
[3, 2]

[1,3] - 1 уже есть в списке 
Проверяем, что индекс текущего элемента - индекс элемента в списке удовлетворяет условию abs(i - j) <= k = 3 - 0 = 3 <= k -> false

Если число не удовлетворяет условию, то в списке в поле его значения перезапишем индекс ноого элемента с таким же значением

Список будет выглдеть так:

[1, 3] - перезаписали
[2, 1]
[3, 2]

Идем далее

[1, 3] 
[2, 1]
[3, 2]

[2, 4] - такой элемент уже есть в списке, проверяем улосвие 

4 - 1 = 3 <= k - true

return true

```Python
class Solution:
    def containsNearbyDuplicate(self, nums: List[int], k: int) -> bool:
        left = 0
        hashmap = {}

        for index in range(len(nums)):
            num = nums[index]

            if num in hashmap:
                # проверяем индекс
                if index - hashmap[num] <= k:
                    return True
                hashmap[num] = index
                continue

            hashmap[num] = index
        
        return False            
```
