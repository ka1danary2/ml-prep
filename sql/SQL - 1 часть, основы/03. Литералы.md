## Литералы
Это указанное явным образом фикисрованное значение, например, число 12 или строка `SQL`

Основными типами литералов в SQL 
- строка
- число
- логический
- NULL
- литерал даты и времени

Строки поддерживают символы экранирования

```sql
SELECT 'Строка \n другая строка' as String
```

Числа могут быть:
- целыми
- вещественными через точку `4.5`
- отрицаительные
- экспоненциальное представление `1e3 (1000), 1e-3 (0.001)`

Операторы:
- Деление по модулю `% или MOD` -> `11 % 5 = 1`
- Умножение 
- Сложение
- Вычитание
- Деление `/`
- Целочисленное деление `DIV`

Дата и время:
- Можно представить просто в виде строки `1970-12-30 или 19701230 
- Или в виде числа 19701230

Дату можно указывать следующими образами:
- Дата формата YYYY-MM-DD, YYYYMMDD, в качестве разделителя можно использовать любой знак препинания или опустить
- Время - hh:mm:ss, hh:mm, hh, ss, разделитель любой или можно опустить
- Дата и время в виде секунд '20200101183030'

Логические литералы
- True
- False

Null
- Нет данных или нет значения
- Нужно чтобы отличать полное отстутствие данных от проблема или строки длины 0
