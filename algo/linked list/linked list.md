У каждого узла есть ссылка на следующий элемент

![[Pasted image 20260414122130.png]]

- HEAD - это первый элемент в списке, на который ничего не указывает
- TAIL -  последний элемент в списке, который ни на что не указывает

Поиск:  O(n)

### Добавление элемента в начало списка О(1)

В новом элементе ссылку next надо установить на узел head
После установить HEAD на только что созданный элемент

### Удаление элемента в начале списка O(1)

Сохранить ссылку на следуюий элемент
В первом элементе надо обнулить (null) ссылку на next
После  установить HEAD на следующий элемент, который мы сохранили в памяти

### Добавление элемента в конец массива O(1)

Установить next у TAIL на новый элемент
Перенести TAIL на новый элемент

### Удаление последнего элемента O(n)

Храним ссылку на элемент CURRENT
Нужно пройтись по всему массиву, пока не встретим ссылку на элемент TAIL
Обновляем TAIL на текущий элемент
У нового TAIL удалить ссылку на следующий элемент (next = null)

### Удаление любого другого элемента O(n)

По аналогии с удаление последнего элемента

Храним ссылку на элемент PREV
Храним ссылку на элемент CURRENT

Нужно пройтись по всему массиву, пока не встретим ссылку на удаляемый элемент
Перенести ссылку на следующий элемент
Ссылку в удаляемом сделать null
