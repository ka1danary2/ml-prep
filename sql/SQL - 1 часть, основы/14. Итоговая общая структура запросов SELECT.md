## Итоговая общая структура запросов со всеми операторами SELECT

```sql
SELECT поля_выборки
FROM имя_таблицы
[WHERE условие_для_строк]
GROUP BY поле_группировки [, ...]
HAVING условие_для_групп
[ORDER BY поле_сортировки];
```

Пример 

Получить минимальную стоимость каждого жилья с телевизором, при этом нас интересует только типы жилья, содержащие как минимум 5 жилых помещений

```sql
SELECT home_type, MIN(price) as min_price
FROM Rooms
WHERE has_tv = true
GROUP BY home_type
HAVING COUNT(*) >= 5
```
