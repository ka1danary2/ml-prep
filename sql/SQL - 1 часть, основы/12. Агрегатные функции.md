## Агрегатные функции

Это функция которая выполняет вычисления на наборе значений и возвращает одиночное значение

Структура

```sql
SELECT {литерал | аргегатная_функция | поле_группировки} [, ...]
FROM имя_таблицы
GROUP BY поле_группировки [, ...]
```

Агрегатные функции
- SUM()
- AVG()
- COUNT() - может работать с NULL
- MIN()
- MAX()
