## Внешние соединения
Возвращает все пары, даже если для второй нет значения, в них подставляет NULL

### Внешнее левое соединение
Возвращает все строки из левой таблицы, для правой выводит либо значение если таковое нашлось, либо NULL

```sql
SELECT Timepair.id "timepair.id", start_pair, end_pair,
    Schedule.id "schedule.id", date, class, number_pair, teacher, subject, classroom
FROM Timepair
    LEFT JOIN Schedule ON Schedule.number_pair = Timepair.id;
```

Благодаря внешним соединениям достаточно просто можно найти нулеве строки, добавив простую фильтрацию

```sql
SELECT Timepair.id, start_pair, end_pair
FROM Timepair
    LEFT JOIN Schedule ON Schedule.number_pair = Timepair.id
WHERE Schedule.number_pair IS NULL;
```

Правое соединнеие зеркалит левое
