Основная идея - проходимся по массиву, если есть ключ с таким же значением - то value = 1, также на каждом шаге проверяем если при добавлени это value = 2 -> то возвращаем сразу true и выходим из цикла
С помощью хештаблиц можно эту задачу решить за $O(n)$
- Начнем цикл от index до len(nums)
- Если nums[index]


```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        hashmap = {}
        for index in range(len(nums)):
            value = nums[index]
            if value in hashmap:
                return True
            else:
                hashmap[value] = 1
        return False
```


## Улучшение по памяти - можно использовать объект set

Можно создать объект `Set` из массива `nums` и сравнить их длину - если  `len(set) < len(nums)` - то в массиве явно есть дубликаты

```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        if len(nums) == len(set(nums)):
            return False
        return True
```
