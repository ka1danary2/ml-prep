**Краткое описание алгоритма**:
Алгоритм нужен для поиска кратчайших путей от стартовой вершины в невзвешенных графах. Граф может быть как ориентированный, так и не ориентированный.

<mark style="background:#d2cbff">O(V + E)</mark>

Структуры:
- Граф - список смежностей
- Очередь FIFO - необработанные вершины
- Словарь - кратчайшие пути

1) Инициализация
	- Расстояния до всех вершин inf
	- Расстояние до стартовой вершины 0
	- Очередь - добавить стартовую вершину
2) Алгоритм
	- Достаем из очереди вершину
	- Начинаем обрабатывать всех ее соседей
		- Если расстояние до соседа = inf
			- обновляем ее расстояние в словаре dist = расстояния текущей вершины + 1
			- добавляем необработанную вершину-соседа в очередь
Свойства:
1) Может определить остовное дерево
2) Также может найти несвязаные вершины

Используется:
- для обхода по уровням
- и поиска компонент

<mark style="background:#d2cbff">bfs</mark> - алгоритм обхода графа в ширину, поиск кратчайшего пути в невзвешенном графе

Нужен если мы хотим узнать, как быстрее всего добраться от города А до любого города

Если граф ориентированный, с ним точно также эти алгоритмы работают

dfs нужен для поиск в глубину, его нельзя использовать для поиска наименьшего пути, так как он не для этого (он просто обходит все ветки)

Работает только на невзвешенном графе, так как это слоистый алгоримт и длина равна сумме пути

**Описание алгоритма:**
 В обходе графа в ширину мы  рассматриваем всех соседей у вершины и как бы проходимся по графу "слоями"

Так мы делаем до тех пор, пока не перберем все ребра

Нужно как-то обеспечить такой порядок обработки вершин

Сначала определяем всех соседей стартовой вершины и только потом начать их обрабатывать

Очередь - мы будем складывать в нее вершины, которые ожидают обработки

Рассмотрим алгорит обработки:
1) init
перед началом обработки мы должны проинициализировать массив расстояний
стартовая вершина, расстояние до нее = 0, а все остальные вершины мы заполним расстояние = бесконечности, это значит мы еще не знаем какое расстояние

Также у нас будет проинициализирована очередь вершин, которые ожидают обработки. Сначала там только стартовая вершина

Далее извлекаем вершины из очереди, когда это происходит можно считать расстояние до вершины окончательным.

Просомтри ее соседей - 1 3, кратчайший путь не знаем, поэтому записываем их в очередь

![[Pasted image 20260531141723.png]]

Далее, закончили со стартовой вершины

Рассмотрим те вершины, расстояние до кооторых = 1
Из очереди первой извлекается вершина 1 - перебираем ее соседей. 0 - мы обработали, а вот вершины 8 у нас новая, записываем расстояние для нее = 2 и помещаем ее в очередь

При извлечении вершины из очереди можно считать, что расстояние до нее явялется окончательным

Далее извлекается вершина 3, 0 пропускаем, обрабатываем вершину 2, расстояие до нее 2, пишем в очередь. Потом 9, расстояние два, пушем в очередь, вершина 7, расстояние два, пишем в очередь

![[Pasted image 20260531141926.png]]

Теперь рассматриваем вершины, расстояние до которых равно двум, достаем их из очереди

Первая из них = 8
В 1 - мы были, не рассматриваем, как и 2, а вот 5 получает расстояние 3 и отправляется в очередь

Вершина 2 - из них не пройдены только 6 и 3, помечаем расстояние до них как 3 и помещаем их в конец очереди

Важные наблюдения:

- Если у нас невзвешенный граф, то bfs может определить остовное дерево
- Также, если есть несвязные вершины в графе, то bfs может помочь определить их наличие (расстояние до них так и останется равным бесконечности)

Моя реализация на пайтон:

```python
import collections

def bfs(graph: dict, start_node: int):
    # очередь для вершин
    q = collections.deque()

    q.append(start_node)

    max_lenght = float('inf')

    # словарь для вершин
    dist = {i: max_lenght for i in graph}
    dist[start_node] = 0

    while q:
        current_vertex_in_queue = q.popleft()

        for neiborhod in graph[current_vertex_in_queue]:
            
            if dist[neiborhod] == max_lenght:
                dist[neiborhod] = dist[current_vertex_in_queue] + 1
                q.append(neiborhod)

    return dist

v, e = map(int, input().split())
graph = {}

for i in range(e):
    a, b = map(int, input().split())

    if a not in graph:
        graph[a] = []

    graph[a].append(b)

    if b not in graph:
        graph[b] = []
        
    graph[b].append(a)

print('Исходный граф', graph)

print(bfs(graph, 0))
```
