
---
**Краткое описание алгоритма**
Алгоритм нужен для обхода всех вершин в графе

Граф - список смежностей <mark style="background:#d2cbff">Ассимптотика (O(V + E)) </mark>

Рекурсивный алгоритм - происходит перебор вершин
- заходим в непосещенную вершину, помечаем ее как посещенную
- запускаем рекурсивно алгоритм для всех непосещенных соседей в глубину

Используется.
- обход графа
- поиск компонент связности
- поиск циклов
- топологическая сортировка
- поиск пути (не кратчайшего)
- поиск мостов (алгоритм Тарьяна)

---
**Полный разбор алгоритма**

dfs - обход по всем вершинам, до которых мы можем дойти

<mark style="background:#d2cbff">Поиск в глубину</mark> - это рекурсивная процедура, аргументами которой является граф (G),  номер текущей вершины (start_vertex) и массив отметок о посещенности вершин (dict)

Заходя в вершину, dfs сначала ее помечает как посещенную и потом запускат рекурсивно обход всех остальных непосещенных соседей в глубину

Отлично подходит для списка смежностей
С матрицей смежностей уже не так хорошо работает (ассимптотика похуже)
#### Общее описание алгоритма dfs:
**Граф** - список смежностей

Пусть граф - это лабиринт, где:
- Вершины - комнаты
- Ребра - это коридоры

**Наша задача** - обойти весь лабиринт

**Стратегия поиска следующая:**
Если из текущей вершины есть соседи (to) то нужно рекурсивно сходить во все комнаты, обойти рекурсивно все пути, пока мы не упремся в конец и рекурсия не закончится

На циклах стратегия простого обхода не будет работать, так как dfs зациклится на нем - чтобы избежать этого, нужно помечать комнаты, в которыз мы были (visited), причем не обязательно только булево значение, там может лежать и другое значение, это может пригодиться при для взвешенных графов. 

Получается,  рекурсивно мы будем проходить не по всем соседям, а только непосещенным соседям, поэтому нужно добавить проверку `not visited(to)` 

**Что делать с несвязными вершинами в графе?**

Если нужно посетить все вершины (например, если не связанная вершина и в нее мы не сможем никак попасть по ребрам из основного графа) то можно запустить цикл по ребрам чтобы точно обойти их все

<mark style="background:#d2cbff">Ассимптотика (O(V + E)) </mark>

Решение для матрицы смежности - его минус в том, что даже если у нас нет из одного ребра в другое дороги, нам все равно придется перебрать все варианты в строке, даже если там нет дороги

<mark style="background:#d2cbff">Ассимптотика для матрицы смежности (O(V^2))</mark>
### Моя реализация алгоритма на python:

```python
def dfs(graph: dict, current_vertex: int, visited: list):
    # сначала отмечаем, что вершина посещана
    visited.append(current_vertex)
    print('Вершина', current_vertex, 'посещена')

    # перебираем соседей графа (граф у нас в виде списка смежностей длял ребра, то есть перебираем соседей)
    for to in graph[current_vertex]:
        if to not in visited:
            dfs(graph, to, visited)

graph = {}

v, e = map(int, input().split())

visited = []

for _ in range(e):
    a, b = map(int, input().split())

    if a not in graph:
        graph[a] = []
    
    graph[a].append(b)

    if b not in graph:
        graph[b] = []
    
    graph[b].append(a)

# for key, value in graph.items():

dfs(graph, 0, visited)
```
