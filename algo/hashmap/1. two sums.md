То есть надо найти такие два числа, которые в сумме двают target и вернуть массив индексов этих чисел

Самый простой варинат - брутфорс, но его сложность $O(n^2)$

## Решение через брутфорс O(n^2)

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                if nums[i] + nums[j] == target:
                    return [i, j]        
```

## Решение через хэшмап (в питоне словари) (O(n))

Пространственная сложность из-за словарей тоже равна $O(n)$

nums = [3, 5, 8, 12]
target = 17

Идея заключается в следующем:
- Начинаем проходить по всему массиве `nums` 
- Проверяем первый элемент под `i = 0`, его `value = 3`
- Считаем разницу между `taget` и `value` = `17 - 3 = 15`, значит нам надо нужен элемент с `value = 15`
- Смотрим, если ли в хештаблице элемент с индексом `15` -> нет, записываем `key = value` `value = i`

```python
hashmap = [
	3 : 0,
]
```

- Переходим к следующему элементу `i=1` `value = 5`, `complement = 17 - 5 = 12`
- Смотрим, есть ли в хенштаблице элемент с `key = 12`-> нет, записывем `key = 5` `value = 1`

```python
hashmap = [
	3 : 0,
	5 : 1
]
```

- Переходим к следующему элементу `i = 2` `value = 8`, `complement = 17 - 8 = 9`
- Есть ли в хенштаблице -> нет, записываем в нее элемент

```python
hashmap = [
	3 : 0,
	5 : 1,
	8 : 2,
]
```

- Переходим к следующему элементу `i = 3` `value = 12`, `complement = 17 - 12 = 5`
- Есть ли в хенштаблице -> да, возвращаем массив индексов `[1, 3]` 

### Решение

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        hashmap = {}
        for index in range(len(nums)):
            number = nums[index]
            complement = target - number
            if complement in hashmap:
                return index, hashmap[complement]
            else:
                hashmap[number] = index
        return null
```
