Решение

Найти подмасив с условием - у подмассива длины 4 должна быть самая большая средняя сумма чисел

```python
class Solution:
    def findMaxAverage(self, nums: List[int], k: int) -> float:
        left = 0
        current_sum = 0

        answer = -float('inf')

        for right in range(len(nums)):
            current_sum += nums[right]
                
            if right - left + 1 == k:
                mid = current_sum / k
                answer = max(answer, mid)
                current_sum -= nums[left]
                left += 1
        
        return answer
```

еще одно решение
```python
class Solution:
    def findMaxAverage(self, nums: List[int], k: int) -> float:
        ma = float('-inf')

        summ = 0
        l = 0

        for i in range(len(nums)):
            summ += nums[i]
            
            if i - l + 1 == k:
                ma = max(ma, summ)
                summ -= nums[l]
                l += 1

        return ma / k
```
