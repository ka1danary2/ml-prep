### Решение

```python
class Solution:
    def firstStableIndex(self, nums: list[int], k: int) -> int:
        max_left = float('-inf')
        
        for index in range(len(nums)):
            max_left = max(max_left, nums[index])
            min_right = min(nums[index:])

            stable = max_left - min_right
            
            if stable <= k:
                return index
                
        return -1
```
