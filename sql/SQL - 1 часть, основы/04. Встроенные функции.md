## Встроенные функции
```sql
SELECT UPPER("Hello world") AS upper_string
```

- NOW(void) - литерал с датой
- LENGTH('name') - строковый литерал длины
- LOWER('string') - литерал в нижнем регистре
- YEAR('2022-06-16') - возвращает год укзанной даты
- INSTR('string-string2') - поиск подстроки в строке с индекса 1, возвращает индекс первого симпола подстроки

Функция выполняет преобразования для каждой строки отдельно

Напишем запрос который высчитывает длину полного имени для каждого члена из семьи

```sql
SELECT member_name,
	LENGTH(member_name) AS fullname_length
FROM FamilyMembers;
```

Получение первых трех букв в строке и преобразование их в заглавные

```sql
SELECT UPPER(LEFT('sql-academy', 3)) AS str;
```

Поиск длины фамилии в строке вида имя<пробел>фамилия

```sql
SELECT member_name, 
	LENGTH(member_name) as full_lenght,
	INSTR(member_name, ' ') AS firstname_with_space_length,
	LENGTH(member_name) - INSTR(member_name, ' ') AS lastname_length
FROM FamilyMembers;
```
