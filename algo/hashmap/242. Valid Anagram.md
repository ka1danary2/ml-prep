Надо найти слово, в котором все буквы составляют другое слово
Анограмма - это когда можно именно что переставить буквы, то есть анограмма должна быть такой же длины как и исходное слово

Я думаю можно попробовать составить две хеш таблицы, где ключ = буква, а значение - это ее количество. Если в этом хешмапе будет достаточное кол-во букв для того чтобы составить второе слово

## Классическое решение черзе хеншмап

1. Проверка, одинаковая ли длина у строк
2. Если да, то строим две хешмпары для двух строк, где ключ - это буква, а значение - это кол-во букв, и в конце просто сравниваем две карты
3. Если они одинаковые - значит можно составить анограмму
4. Иначе нельзя

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False
        hashmap_s = {}
        hashmap_t = {}

        for index in range(len(s)):
            if s[index] in hashmap_s:
                hashmap_s[s[index]] += 1
            else:
                hashmap_s[s[index]] = 1
        for index in range(len(t)):
            if t[index] in hashmap_t:
                hashmap_t[t[index]] += 1
            else:
                hashmap_t[t[index]] = 1
        if hashmap_s == hashmap_t:
            return True
        return False
```


## Решение через класс Counter

Counter - класс, который считает вхождения того или иного элемента в класс

```python
from collections import Counter

class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if Counter(s) == Counter(t):
            return True
        return False
```
