### Краткий алгоритм

**Правило:**
В графе есть цикл, если при обходе в глубину мы встретили вершину, которую мы начали, но еще не закончили обрабатывать

Структуры:
- Список **visited** с тремя состояниями
- Граф в виде списка смежностей
-  Флаг hasCicle

Алгоритм:
- Начинаем обход и стартовой вершины
- Заносим стартовую вершину в visited и ставим ей статус 1
- Перебираем всех ее соседей
	- Если сосед не в списке visited
		- То тогда начинаем идти по нему и меняем состояние вершины родителя и вершины дитя на 1 (в процессе)
	- Или если вершина уже в visited и ее состояние = 1
		- То тогда мы нашла цикл, hasCicle = True

### Подробный разбор

Первое, что приходит в голову по тому, как можно определить цикл - если мы при обходе графа вернемся в вершину, в которой мы уже побывали (которая находится в списке visited), то тогда это цикл

Но это не всегда так работает, потому что может быть такой граф, где нет цикла, но непройденная до конца вершина все равно посмотрит на пройденную вершину

![[Pasted image 20260612082917.png]]



Стартуем из 1, начинаем перебирать ее соседей
- идем из 0 в 1, заносим в в visited
- идем из 1 в 2, заносим в visited
	- у 2 больше нет соседей, возвращаемся в 1
	- у 1 больше нет соседей, возвращаемся в 0
- идем из 0 в 2, заносим в visited
И вот тут мы видим, что 2 так-то уже в visited числится как пройденная вершина, но цикла в графе нет

Рассмотрим теперь граф, в котором есть цикл
![[Pasted image 20260612083213.png]]

Стартуем из вершины 1
- Первый сосед 1
- Рассмотрим соседей 1
	- У нее сосед 2
		- Рассмотрим соседа у 2
			- У нее сосед 1? Но 1 еще не в visited, так как понять, что это цикл?
Надо обратить внимание на то, что на самом деле у вершины не 2 состояния, а 3
- Не посещена - 0
- В процессе - 1
- Завершена - 2
И видно, что если вершина, которая еще не до конца посещена, упирается в еще не законченную вершину

Мое решение на питоне (для ориентированных графов, для неориентированных он не сработает)

```python
def dfs(grapf_local, visited_local, start_vertex):
    visited_local[start_vertex] = 1

    for neibor in grapf_local[start_vertex]:
        if neibor in visited_local and visited_local[neibor] == 0:
            if dfs(grapf_local, visited_local, neibor):
                return True
        elif visited_local[neibor] == 1:
            return True
    
    visited_local[start_vertex] = 2
    return False
```

**Мое решение для неориентированных графов**

В этом случае нужно еще и передавать родителя, чтобы не посчитать ее циклом при попадании в нее

```python
def dfs(graph: dict[str, list], visited: dict[str, int], start: str, parent=None) -> bool:
    # мы пришли в вершину, мы в процессе ее обхода, поэтому статус = 1
    visited[start] = 1

    for to in graph[start]:
        if to == parent:
            continue
        if visited[to] == 0:
            if dfs(graph, visited, to, start):
                return True
        elif visited[to] == 1:
            return True
    
    visited[start] = 2

    return False
```
