## REGEXP (или RLIKE в зависимости от субд)
Поиск и обработка строковых данных с помощью регулярок

LIKE проверяет всю строку, а регулярка может смотреть на подстроку в строке

Синтаксис

```sql
WHERE поле_таблицы REGEXP шаблон;
```

- Нет чувствительности к регистру
- Спец символы экранируются через `\\`
![[Pasted image 20261018162116.png]]
Примеры

- Получить всех пользователей, чьи имена начинаются на John

```sql
SELECT * FROM Users
WHERE name
REGEX '^Jogh'
```

^ - выражение соответствует началу строки

- Вывести все школьные предметы, название которых оканчивается на букву e или у

```sql
SELECT * FROM Subject
WHERE name REGEX '[ey]$'
```

- Найти всех у кого адрес оканчивается на **«@outlook.com» или на «@icloud.com»:**

```sql
SELECT * FROM Users WHERE email REGEXP '@(outlook\\.com|icloud\\.com)$'
```

- Номер телефона не содержит цифр **«2» и «8»:**

```sql
SELECT * FROM Users WHERE phone_number REGEXP '^[^28]*$'
```

- Номер телефона начинается на +7
```sql
SELECT name, phone_number FROM Users WHERE phone_number REGEXP '^\\+7'
```

- Проверка того что в адресе содержится строка Avenue

```sql
SELECT id, address FROM Rooms
WHERE address REGEXP 'Avenue';
```
