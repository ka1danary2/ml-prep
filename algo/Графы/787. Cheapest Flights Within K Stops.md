Ссылка на задачу - https://leetcode.com/problems/cheapest-flights-within-k-stops/description/

Нужно применить алгоритм Белмана-форда [[4 Алгоритм Беллмана-Форда]] так как в задаче просят совершить определенное количество шагов, а именно k шагов. Этот алгорим как раз таки и позволяет совершить при обходе определенное количество шагов.

Также, важно тут создавать копию оригинального массива расстояний, чтобы при поиске нового расстояния ссылаться на него.

Мое решение
```python
class Solution:
    def findCheapestPrice(self, n: int, flights: List[List[int]], src: int, dst: int, k: int) -> int:
        prices = {i: float('inf') for i in range(n)}

        prices[src] = 0

        for _ in range(k + 1):
            new_dist = prices.copy()
            for (parent, to, w) in flights:
                    new_weight = prices[parent] + w
                    new_dist[to] = min(new_dist[to], new_weight)
            
            prices = new_dist

        if prices[dst] != float('inf'):
             return prices[dst]
        return -1
```
