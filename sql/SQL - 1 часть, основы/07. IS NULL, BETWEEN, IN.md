## IS NULL, BETWEEN, IN

Можно использовать в условных запросах

IS NULL
Проверка отсутствия значения в поле

BETWEEN
Проверка расположения числа в интервале, границы включены

```sql
SELECT * FROM Payments
WHERE unit_price BETWEEN 100 AND 500
```

IN
Входит ли значение в кортеж определенных значений

```sql
SELECT * FROM FamilyMembers
WHERE status IN ('father', 'mother');
```
