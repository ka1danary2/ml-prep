Алгоритм позволяет найти подмассив с максимальной суммой в массиве

В чем суть
- На каждом элементе мы будем искать текущий максимум и глобальный максимум
```python
cur = max(item, cur + item)
gl = max(gl, cur)
```

Весь алгоритм выглядит так
```python
def maxSubArray(nums: List[int]) -> int:
    cur = nums[0]
    gl = nums[0]

    for item in nums[1:]:
        cur = max(item, cur + item)
        gl = max(gl, cur)

    return gl

print(maxSubArray([-2,1,-3,4,-1,2,1,-5,4]))
```
