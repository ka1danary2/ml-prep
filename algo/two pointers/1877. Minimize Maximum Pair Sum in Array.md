## Решение

Задача проще  задачи [[Суммарный профессионализм сплоченной команды]]

Для этой задачи 100 процентов нужно пояснение, потому что сразу я не доперла что такое минимизировать максимальные суммы

От нас требуется, чтобы все суммы элементов были минимизированы, очевидно для этого надо самое большое число сложить с самым маленьким и тд, таким образом уравновесив все суммы

Решение
- Отсортировать массив
- И сравнивать пары между собой с конца и начала

```python
class Solution:
    def minPairSum(self, nums: List[int]) -> int:
        nums.sort()
        left = 0
        right = len(nums) - 1

        answer = 0
        while right > left:
            answer = max(answer, nums[right] + nums[left])
            left += 1
            right -= 1
        
        return answer
```

Я бы этот алгоритм отнесла к жадникам

Сложность моего решения $O(n log n)$ потому что сортировка $O(log n)$ а алгоритм поиска пары занимает $O(n / 2) = O(n)$
