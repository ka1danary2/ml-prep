## Многотабличные запросы

Запросим информацию о тратах на покупки

```sql
SELECT family_member, amount * unit_price AS price FROM Payments
```

Было бы удобнее выводить имена людей из другой таблицы

Общий синтексис объединения таблиц

```sql
SELECT поля_таблиц
FROM таблица_1
[INNER | {LEFT | RIGHT | FULL} [OUTER]] JOIN таблица_2
ON условие_соединения
[, ...]
```

- INNER - внутреннее соединение, в результат войдут те, у кого нашлась пара (по умолчанию)
- OUTER - это просто слово, которое ни на что не влияет, но подчеркивает, что соединение внешнее
- LEFT | RIGHT | FULL - внешнее соединение, левое, правое, полное, кроме пар в результат попадут и строки без пар из левой, правой или обеих таблиц
- условие - правило, по которому строки двух таблиц находят пару

Модифицируем прошлый запрос

```sql
SELECT family_member, member_name, amount * unit_price AS price
FROM Payments
	INNER JOIN FamilyMembers
		ON Payments.family_member = FamilyMembers.memver_id
```

Правда теперь оператор * означает вывод всех атрибут из всех таблиц

Если мы хотим вывести все атрибуты конкретной таблицы, то достаточно перед * поставить название таблицы

```sql
SELECT family_member, member_name, FamilyMembers.* unit_price AS price
FROM Payments
	INNER JOIN FamilyMembers
		ON Payments.family_member = FamilyMembers.memver_id
```

Рекомендуется использовать алиасы

```sql
SELECT cl.name, sc.student FROM Class as cl 
    JOIN Student_in_class as sc
    ON cl.id = sc.class
```

То есть итоговая структура внутреннего запроса будет выглядеть вот так:
```sql
SELECT поля_таблиц
FROM таблица_1
[INNER] JOIN таблица_2
    ON условие_соединения
[...]
```

И главное отличие внутреннего и внешнего запроса в следующем:
- внутреннее соединение строгое, оно выводит только строки, которые нашлись в обеих таблицах
- внешнее соединение не строгое, оно выводит строки, которые нашлись с одной из сторон, пустым значениями присваивает NULL

Для внутреннего соединения таблиц можно также использовать и WHERE

```sql
SELECT family_member, member_name FROM Payments, FamilyMembers
	WHERE Payments.family_member = FamilyMembers.member_name
```

Пример запросы из нескольких таблиц и фильтрацией
```sql
SELECT gd.good_name
FROM Payments as pay
INNER JOIN FamilyMembers as fm
ON pay.family_member = fm.member_id
JOIN Goods as gd
ON pay.good = gd.good_id
WHERE fm.status = 'son'
```

Пример запроса с группировкой
```sql
SELECT rv.room_id, AVG(rw.rating) as avg_score
FROM Reservations as rv
JOIN Reviews as rw
ON rw.reservation_id = rv.id
GROUP BY rv.room_id
```
