Можно посчитать префиксные суммы и если сумма в двух местах одинаковая, то значит что сумма на отрезке с началом и концом в позициях на которых достигается префиксная сумма будет равна 0

Каждый раз когда мы встречаем префиксную сумму надо понять, сколько раз мы эту сумму уже видели в прошлый раз и к ответу надо прибавить кол-во

```python
def countPrefix(nums):
	# список для хранения сумм и их кол-ва
	prefixSumByValue = {0: 1} # надо для корректной обработки отрезков которые могут быть прижаты к левому краю
	nowSum = 0
	
	# далее идет довольно классический подсчет сумм, но мы храним значения не в массиве, а в словаре
	
	for now in nums:
		# прибавляем значение в сумму
		nowSum += now
		
		 # если такая сумма еще не в словаре, то записываем ее
		if nowSum not in prefixSumByValue:
			prefixSumByValue[nowSum] = 0
		
		# и если она уже в словаре то прибавляем 1
		prefixSumByValue[nowSum] += 1
		
	return prefixSumByValue

def countZeroSumrange(prefixsymbyvalue):
	countRange = 0
	
	# перебор сумм в словаре
	for nowSum in prefixSumByValue:
		# сколько раз встретилась сумма в словаре
		cntsum = prefixsymbyvalue[nowSum]
		
		# комбинаторная формура - сколько пар для левой и правой границы это создает (вот это надо подразобрать)
		countRange += cntsum * (cntsum - 1) // 2
	return countRange	
```
