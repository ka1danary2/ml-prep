## Подзапросы
Это запрос в другом sql запросе, обычно выполняется перед выполнение основного запроса

В результате подзапрос как и обычный запрос может вернуть
- Литерал
- Один столбец
- Один столбец и одна строка
- Несколько строк с одним столбцом
- Несколько строк с несколькими столбцами

Спсиок всех бронирований самого дорогого жилого помещенеия на данный момент

```sql
SELECT *
FROM Reservations
	WHERE Reservations.room_id = (
		SELECT id FROM Rooms
		ORDER BY price DESC LIMIT 1
	)
```

Далее рассмотрим все виды подзапросов

### Подзапрос с одной строкой с одним столбцом (скалярный подзапрос)

Возвращает один столбец и строку

Чаще всего используется в условиях ограниченной выборки с помощью оператора сравннеия < > <= >= =

Для использования с операторами сравнения важно чтобы подзапрос возвращал скаляр, иначе будет ошибка

Можно использовать прям в SELECT (...) FROM Table, но только скаляр

Можно использовать для фильтрации строк с помощью WHERE

```sql
SELECT * FROM FamilyMember
	WHERE birthday = (SELECT MAX(birthday) FROM FamilyMember)
```

Такой подход может вернуть не одного человека, как если бы мы написали запрос без подзапроса

```sql
SELECT * FROM FamilyMember
ORDER BY birthday DESC
LIMIT 1
```

Это вернет самого младшего человека, но если их будет два, то он вернет лишь одного, а подзапрос позволяет всех младших вернуть

Задача
Выведите всю информацию о пользователе из таблицы Users, кто является владельцем самого дорогого жилья (таблица Rooms).

![[Pasted image 20261019152534.png]]
Решение
```sql
SELECT * FROM Users
WHERE id = (SELECT owner_id FROM Rooms
WHERE price = (SELECT MAX(price) FROM Rooms))
```
