Мое решение 

Я думаю, эту задачу можно решить через обход графа в ширину, где соседями будут являться `(r, c + 1)`, `(r, c - 1)`, `(r + 1, c)` and `(r - 1, c)` на каждой клетке. Для каждой клетки также необходимо считать ее безопасность, то есть у родителя надо обновляться каждый раз манхетонское расстояние до близлежайшей 1 и хранить в словаре их
