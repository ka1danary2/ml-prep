## LIKE
Проверка соответствия строки определенному шаблону

Нужен для нетривиальных поисков по строковым полям

```sql
WHERE поле_таблицы [NOT] LIKE шаблон_строки
```

Может содердать спец символы
- % - любая последовательность символов
- _ - ровно 1 символ

Пример запроса

```sql
SELECT name, email FROM Users
WHERE email LIKE '%@hotmail.%'
```

Экранирование спец символов в LIKE запросах, тогда надо перед спец сиволами поставить бекслеш.

```sql
SELECT job_id FROM Jobs
WHERE progress LIKE '3\%';
```

Escape-символ
Можно вместо по умолчанию символы экарнирования '\' передать какой-то другой символ, например '!'

Синтаксис

```sql
SELECT поле_таблицы LIKE шаблон_строки ESCAPE символ_экранирования
```

```sql
SELECT job_id FROM Jobs
WHERE progress LIKE '3!%' ESCAPE '!';
```
