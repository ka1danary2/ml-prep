**Короткое описание алгоритма**
Алгоритм нужен для поиска кратчайших путей от стартовой вершины на взвешенных графах.
Не работает на отрицательных весах

<mark style="background:#d2cbff">O(E log V)</mark>

Структуры:
- Граф - список смежностей (словарь)
- Куча - улучшенные вершины с приоритетом
- Расстояния - словарь с расстояними до вершин

Инициализация
- Расстояния - заполняем inf
- Стартовая вершина, ее вес = 0 -> добавляем в кучу

Алгоритм:
- Достаем верх с кучи
- Смотрим соседей элемента
	- Новое возможое расстояние - вес вершины + вес соседа
	- Если новое возможное расстояние улучшилось - то обновляем его в словаре с расстоянием и добавляем элемент в кучу
- Повторяем, пока в куче есть элементы

Не работает с отрицательными весами потому что нет фиксированного количества прогонов и на отрицательном ребре граф может зациклиться, постоянно улучшая результат ходя по одному и тому же пути

Не работает с отрицательными весами потому что используется жадный подход

Процесс улучшения показателей веса дял конца ребра во взвешенном графе называется релаксацией

Зафиксируем наблюдение
Из всех вершин, расстояния до которых еще не является окончательным, можно выбрать ближайшую и помететить расстояние до нее как окончательное. Вокруг этой идеи и базируется весь алгоритм поиска кратчайшего пути на взвешенном графе при весе ребра >= 0

Псевдокод алгоритма:
- Инициализация
Расстояние до стартовой вершины = 0
Расстояние до остальных вершин = float('inf')
- Повторить V раз
Из всех вершин, расстояния до которых еще не являются окончательными, выбрать ближайшую и пометить расстояние до нее как окончательное. Поместить его в кучу с приоритетом

Затем просомтреть ребра из этой вершины и попробовать улучшить расстояни до вершин соседей (ну то есть повторить цикл для элемента с наименьшим приоритетом)

Мое решение дейкстры на куче

```python
import heapq

def deikstra(graph: dict, start_position: int):
    max_lenght = float('inf')
    start_s = 0

    # словарик с расстояними, изначально заполняем бесконечностью
    # он будет заполняться при улучшении показателя растсояния для вершины
    dist = {i: max_lenght for i in graph}
    q = []

    dist[start_position] = 0

    # пушим в кучу расстояние до стартовой точки (оно 0)
    # куча сортирается по 1 элементу, так что сначала стоит вес потом само ребро
    heapq.heappush(q, (start_s, start_position))

    while q:
        # достаем вершину с минимальным приоритетом из кучи
        priority, current_min_q = heapq.heappop(q)

        print('Текущий минимальный элемент в куче - ', current_min_q)
        print('и его приоритет - ', priority)

        for item in graph[current_min_q]:
            item_ptiority = item[1] 
            item_value = item[0]
            # пробегаемся по элементам, где первое значение в паре - это сама вершниа, второе - его вес
            weight = item_ptiority + priority

            # нужна проверка - если в словаре уже есть этот элемент расстояние до него меньше, то обнолвяем его
                
            if weight < dist[item_value]:
                dist[item_value] = weight
                heapq.heappush(q, (weight, item_value))

    return dist

graph = {}

# нужно не забыть сохранить еще и вес между ребрами

    a, b, w = map(int, line.split())

    graph[a].append((b, w))

    if b not in graph:
        graph[b] = []
    
    graph[b].append((a, w))

print('Итоговый граф', graph)
```
