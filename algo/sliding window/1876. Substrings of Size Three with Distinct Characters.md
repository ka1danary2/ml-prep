Решение

Надо решать задачу так, будто бы 3 элемента могут быть не 3, а 10, или вообще какое угодно число

Такое решается только скользящим окном, потому что надо запоминать что было в окне

1. left = 0, right = 0
2. hashmap = {}  # символ -> количество в окне
3. answer = 0

Цикл по right от 0 до конца строки:
    - добавляем s[right] в hashmap (увеличиваем счетчик)
    
    - если right - left + 1 > 3:  # окно больше 3
        - уменьшаем счетчик s[left]
        - если счетчик стал 0 → удаляем ключ
        - left += 1
    
    - если right - left + 1 == 3 и len(hashmap) == 3:
        - answer += 1

Вернуть answer

```python
class Solution:
    def countGoodSubstrings(self, s: str) -> int:
        left = 0        
        hashmap = {}

        answer = 0

        for right in range(len(s)):
            if s[right] in hashmap:
                hashmap[s[right]] += 1
            else:
                hashmap[s[right]] = 1

            # Размер окна больше 3
            if right - left > 2:
                hashmap[s[left]] -= 1

                # Полное удаление из хештаблицы
                if hashmap[s[left]] == 0:
                    del hashmap[s[left]]

                left += 1
                                
            if len(hashmap) == 3 and right - left == 2:
                answer += 1
            
        return answer
 
```
