Задача похожа на [[560. Subarray Sum Equals K - это пиздец]]


Тестовый пример
nums = [1, -1, 5, -2, 3]
k = 3

maxSizeSubArray = 0
prefixCurrentSum = 0

{0: 0}

---
0 - item = 1
prefixCurrentSum = 0 + 1 = 1
difference = 1 - 3 = -2

{0: 0} {1: 1}

----
1 - item = -1
prefixCurrentSum = 1 - 1 = 0
difference = 0 - 3 = -3

Ничего не меняется, так как в хешмапе уже есть  элемент с индексом меньше, мы ищем максимальную длину, так что оставляем наименьший индекс в хештаблице

{0: 0} {1: 1}

---
2 - item = 5
prefixCurrentSum = 0 + 5 = 5
difference = 5 - 3 = 2

{0: 0} {1: 1} {2: 3}

---
3 - item = -2
prefixCurrentSum = 5 - 2 = 3
difference = 3 - 3 = 0

0 есть в списке значит меняем максимальную длину для подмассива
	lenght = 3 - 0 + 1 = 4

maxSizeSubArray = 4

---- 

### Решение
```python
def findMaximumSizeSubArray(nums: List[int], k : int):
	prefixSumList = {
		0: -1
	}
	prefixCurrentSum = 0
	maxSizeSubArray = 0
	
	for index in range(len(nums)):
		item = nums[index]
		
		prefixCurrentSum += item
		difference = prefixCurrentSum - k
		
		if difference in prefixSumList:
			lenght = (index - prefixSumList[difference])
			maxSizeSubArray = max(maxSizeSubArray, lenght)
		
		if not(prefixCurrentSum in prefixSumList):
			prefixSumList[prefixCurrentSum] = index
		
	return maxSizeSubArray
		
nums = [1, -1, 5, -2, 3]
k = 3

print(findMaximumSizeSubArray(nums, k))
```
