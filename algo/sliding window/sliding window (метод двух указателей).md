Скользящее окно

Используется для поиска подстроки или подмассива, обладающим каким-то свойством, например, уникальностью всех символов

**Сложность:** O(n)

Скользящее окно — это два указателя (`left`, `right`), которые задают **непрерывный кусок массива**,  
и этот кусок **всегда удовлетворяет условию**.

ТО ЕСТЬ СКОЛЬЗЯЩЕЕ ОКНО УЧИТЫВАЕТ ВЕСЬ КОНТЕКСТ ВНУТРИ ДВУХ УКАЗАТЕЛЕЙ (ДЕРЖИТ КОНТЕКСТ И ЕСТЬ СТЕЙТ)

В ТО ВРЕМЯ КАК ДВА УКАЗАТЕЛЯ ЗНАЮТ ТОЛЬКО ОБ ЭЛЕМЕНТАХ НА УКАЗАТЕЛЯХ

👉 Окно:

- **расширяется** (двигаем `right`)
- **сужается** (двигаем `left`, если условие нарушилось)

! мы **не пересчитываем окно заново**, а **поддерживаем его состояние**

В отличие от двух указателей скользящее окно всегда определяет непрерывный кусок массива, который всегда удовлетворяет заданному условию, может расширяться или сужаться 

Допустим, задача - вернуть длину наибольшей подстроки, в которой нет одинаковых символов

Второй метод - скользящее окно

1. Увеличиваем  right пока в подстроке нет повторяющихся символов
2. Сужаем подстроку (если в подстроку попали повторяющиеся символы) - увеличивает left пока в подстроке есть повторяющиеся символы
3. Повторяем с пункта 1
4. Самое главное - число максимальной подстроки мы запоминаем, и перезаписываем когда найдена более длинная строка

```python
def longestSubstring(s: str):
    answer = 0
    left = 0
    set_s = set()

    for right in range(len(s)):
        char = s[right]

        while char in set_s:
            set_s.remove(s[left])
            left += 1

        set_s.add(char)
        answer = max(answer, right - left + 1)

    return answer	
```
