Задача решается таким же способом, как и обычная версия задачи

```python
class Solution:
    def twoSum(self, numbers: List[int], target: int) -> List[int]:
        hashmap = {}
        for index in range(len(numbers)):
            complement = target - numbers[index]

            if complement in hashmap:
                return (hashmap[complement] + 1), (index + 1)
            hashmap[numbers[index]] = index
```

Но, если у нас именно отсортированный массив, то эту задачу можно более оптимально решить с помощью двух указателей (по памяти)

Если $a[i] + a[j] > target$ где $i<j$
то можно заметить, что
$a[i] + a[target]$ где $m > j$ не будут подходить

Если $a[i] + a[j] < target$
то можно заметить, что
$a[n] + a[j]$ где $n < j$ не будут подходить

Сформулируем алгоритм

1. Если сумма чисел двух указателей меньше таргет, то сдвигаем левый указатель вправо
2. Если сумма чисел двух указателей больше таргет, то правый двигаем влево
3. Если сумма равна - то выводим пару
4. Выполняем пока правый не наткнется на левый
5. Первый указатель на 0 позиции, правый на крайней справа

Смысл в том, что если мы в отсортированном массиве будем складывать от начала и от конца, то мы будем получать сначала самое маленькое возможное число с самым большим, если все таки таргет меньше, логично надо уменьшать второе число, так как первое не уменьшить, ну и если таргет больше суммы, логично что надо увеличить левый край

```python
class Solution:
    def twoSum(self, numbers: List[int], target: int) -> List[int]:

        # Решение через хешмап
        # hashmap = {}
        # for index in range(len(numbers)):
        #     complement = target - numbers[index]

        #     if complement in hashmap:
        #         return (hashmap[complement] + 1), (index + 1)
        #     hashmap[numbers[index]] = index

        # Решение через указатели
        pointer1 = 0
        pointer2 = len(numbers) - 1
        while(pointer1 < pointer2):
            if numbers[pointer1] + numbers[pointer2] < target:
                pointer1 += 1
                continue
            if numbers[pointer1] + numbers[pointer2] > target:
                pointer2 -= 1
                continue
            else:
                return pointer1 + 1, pointer2 + 1
```
