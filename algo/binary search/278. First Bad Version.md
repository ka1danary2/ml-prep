Нужно найти первую некоректную версию
Нам дана только длина массива, версия нумеруются друг за другом целыми числами
Мы знаем, что после первой некорректной версии все последующие также некоректные
Также предоставляется функция, которая возвращает `true`, если номер версия некоректный и наоборот

Следовательно, нужно пытаться решаться задачу от того, является ли рассматриваемая версия корректной

Задача на поиск, значит используем бинарную сортировку

Мое первое решение
```python
# The isBadVersion API is already defined for you.
# def isBadVersion(version: int) -> bool:

class Solution:
    def firstBadVersion(self, n: int) -> int:
        left = 1
        right = n
        badVersion = 0

        if(n == 1):
            return n

        while(left <= right):
            mid = left + (right - left) // 2
            
            # если плохая версия
            if(isBadVersion(mid)):
                right = mid - 1
                if(not isBadVersion(mid - 1)):

                continue
            else:
                left = mid + 1
                continue

        return mid
```

class Solution:

        left = 1
        right = n
                
        while(left < right):
            mid = left + (right - left) // 2

            # если плохая версия

                right = mid
                continue
            # если хорошая версия, значит, что и все слева хорошее и сама версия тоже хорошая
