 Решение за O(NM)

Просто перебор и проверка

```Python
def countZeroes(nums, l, r):
	cnt = 0
	for i in range(l, r):
		if nums[i] == 0:
			cnt += 1
	return cnt
```

Можно применить префиксные суммы, и для каждого префикса будем считать кол-во нулей на нем prefixZeroes

Тогда ответ на запрос на полуинтервале будет  prefixZeroes[R] -  prefixZeroes[L]

```python
def countZeroesPrefix(nums):
	prefixZeroesSum = [0] * (len(nums) + 1)
	for i in range(l, r):
		if nums[i - 1] == 0:
			prefixZeroesSum[i] = prefixZeroesSum[i - 1] + 1
			continue
		prefixZeroesSum[i] = prefixZeroesSum[i - 1]
	return prefixZeroesSum
	
	
def countZeroesPrefix(nums, l, r):
	return prefixZeroes[r] - prefixZeroes[l]
```
