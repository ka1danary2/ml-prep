Ссылка на задачу https://leetcode.com/problems/find-the-city-with-the-smallest-number-of-neighbors-at-a-threshold-distance/description/

Мое решение базируется на алгоритме флойда [[5 Алгоритм Флойда-Уоршела]]

Решение
```python
class Solution:
    def findTheCity(self, n: int, edges: List[List[int]], distanceThreshold: int) -> int:
        max_len = float('inf')

        initMatrix = [[max_len] * n for _ in range(n)]
        
        # надо построить матрицу связанности

        for i in range(n):
            initMatrix[i][i] = 0

        for a, b, w in edges:
            initMatrix[a][b] = w
            initMatrix[b][a] = w

        for i in range(n): # промежуточные вершины
            for a in range(n): #откуда
                for b in range(n): # куда
                    news_weight = initMatrix[a][i] + initMatrix[i][b]
                    initMatrix[a][b] = min(initMatrix[a][b], news_weight)
                      
        lenght = [0] * n
        minimum = max_len
        index = 0

        for i in range(n):
            for j in range(n):
                if i != j and initMatrix[i][j] <= distanceThreshold:
                    lenght[i] += 1
            if lenght[i] <= minimum:
                minimum = lenght[i]
                index = i   

        return index  
```
