## Решение

Поиск подстроки или подмассива с определенным условием (в данном случае условие - нет повторяющихся символов) это всегда задачи на скользящее окно

Будем проходиться по строке, запоминать длину самой длинной строки и сохранять ее в ответ

Если вдруг следующий символ уже есть в подстроке - в таком случае нужно сократить подстроку с левого указателя так, чтобы в ней не было этого символа, тогда можно будет добавить следующий

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
    left = 0
    answer = 0
    ss = set()
    
    for right in range(len(s)):
	    current_char = s[right]
	    
	    while current_char in ss:
		    ss.remove(s[left])
		    left += 1
		
		ss.add(current_char)
		answer = max(answer, right - left + 1)
		
	return answer        
```


```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        max_l = 0
        l = 0
        sets = set()

        for r in range(len(s)):
            el = s[r]

            while el in sets:
                sets.remove(s[l])
                l += 1

            sets.add(el)

            max_l = max(max_l, len(sets))
            
            
        return max_l
```

Можно оптимизировать код с хешмапой - добавить хешмапу и там хранить последний индекс символа в строке, и когда надо будет удалить что-то из строки, то мы l просто сместим на значение в хешмапе, это будет быстрее
