### Числа
Несколько чисел в одной строке

```python
a, b, c = map(int, input().split())
```

Массив чисел неизвестной длины

```
arr = list(map(int, input().split()))
```

Несколько строк с числами

```
3
10 20
30 40
50 60
```

```python
n = int(input())
pairs = []

for _ in range(n):
	a, b = map(int, input().split())
	pairs.append((a, b))
```

Матрица
```
3 4
1 2 3 4
5 6 7 8
9 0 1 2
```

```python
n, m = map(int, input().split())

matrix = []
for _ in range(n):
	row = list(map(int, input().split()))
	matrix.append(row)
```

### Строки

```
hello
world
```

```python
s = input()           # одна строка
s = input().strip()   # с обрезкой пробелов/переводов на всякий
```

`strip` удаляет лишние строки пробелы и символы с начала и конца строки
## Считывание матрицы неизвестной длины
```python
matrix = []

while True:
	line = input()
	if not line:
		break
		
	stringToList = line.split()
	
	matrix.append(list(map(int, stringToList))
```

## Немного про map и split
`map` применяет функцию к списку и возвращает итератор

Чтобы итератор превратился в обычный массив, нужно его обернуть в функцию `list(iterator)` которая превращает итератор в класс `list`

`split` разбивает строку и убирает символы разделители из нее
Есои в аргументы функции ничего не передавать, то она автоматически уберет все символы разделители, это табы, пробелы и так далее
