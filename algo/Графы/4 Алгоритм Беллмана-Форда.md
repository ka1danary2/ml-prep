**Краткое описание алгоритма:**
Алгоритм нужен для поиска кратчайших путей от стартовой вершины на взвешенных графах.

Также алгоритм нужен, когда у нас есть определенное количество шагов, например, нужно составить маршрут с определенным количеством остановок

Может обнаружить отрицательные циклы

Работает на отрицательных весах.

<mark style="background:#d2cbff">O(VE)</mark>

Структуры:
- Граф - список ребер [(a, b, w)]
- Словарь расстояний

Инициализация:
- Словарь расстояний заполняется бесконечностью
- Расстояние до стартовой вершины = 0

Алгоритм:
- Цикл до V - 1
	- Если расстояние до a не равно inf, то считаем новое расстояние, которое равно расстояние до a + расстояние до b
	- Если оно улучшилось, то записываем его в словарь расстояний
Свойства:
- Каждая итерация Беллмана добавляет ровно одно ребро к пути. Поэтому когда в задаче есть ограничение на количество шагов или вершин, то можно пробовать использовать Беллмана
Использование:
- умеет обнаруживать отрицательные циклы

**Полное описание алгоритма:**

Поиск кратчайших путей когда в графе есть отрицательные вершины (в отличие от Дейкстры)

Если граф неориентированый, то просматривать ребра стоит в обе стороны

Наблюдения

- при попытке обновить расстояние вдоль каждого из ребер графа есть правильно вычисленные длины кратчайших путей, это ребра путей и 1 ребра
- попробуем еще раз обновить расстояние вдоль каждого из ребер графа, после этого будут правильно вычислены длины кратчайших путей из 2 ребер
...
- тоже самое будет и для всех ребер

Мы знает, что в дереве количество ребер = V - 1

Кратчайший путь без циклов содержит максимум V-1 ребро - потому что в графе V вершин и путь не может проходить через одну вершину дважды. За каждую итерацию гарантированно находим кратчайший путь длиной хотя бы в одно ребро. Поэтому V-1 итераций достаточно чтобы найти все кратчайшие пути.

Следовательно, чтобы гаратированно вычислить длины всех кратчайших путей будет достаточно V - 1 раз обновить расстояние вдоль каждого из ребер графа

! для форда беллмана самый удобный вариант - это просто список ребер

Также, так как в графе есть отрицательные ребра, надо добавить доп условие, что расстояние до начала ребра не равно бесконечности. Тогда мы избежим сиуации что из бесконечности будут вычитаться отрицательные расстояния

То есть основная суть алгоритма в том, чтобы просто перебрать все ребра у графа v - 1 раз и каждый раз улучшать значения, в итоге они будут наилучшими

![[Pasted image 20260601151612.png]]

Ассимптотика - O(VE)

Нужно стараться все таки не использовать данный алгоритм, его надо использовать если графы в задаче достаточно маленькие и можно не вспоминать другие алгоритмы

В бамбуке алгоритм будет работать дольше всего

Иногда этот алгоритм модифицируют для того, чтобы отслеживать, улучшилось ли у нас расстояние

![[Pasted image 20260601152034.png]]

если ни на одной вершины не произошла релаксация то это значит что и дальше их не будет и это значит что мы нашли финальный результат и можно завершить цикл

есть еще способ улучшить этот алгоритм

- на первой итерации имеет смысл просматривать только ребра, исходящие из стартовой вершины (у остальных dis[a] = inf)
- на следующих итерациях имеет смысл просматривать только ребра расстояние до начала которых улучшилось на предыдущей итерации

Моя реализация на python
```python

def belman_ford (graph: list, start_vertex: int, v: int):
    max_lenght = float('inf')
    start_vertex_lenght = 0

    # сначала длина до всех бесконечность
    dist = {i: max_lenght for i in range(v)}

    # длина до стартовой вершины всегда 0
    dist[start_vertex] = start_vertex_lenght

    for _ in range(v-1):
        for (u, to, w) in graph:
            # print('граф', u, e, w)

            # расстояние до прошлого ребра + текущий вес
            if dist[u] != max_lenght:
                weight = dist[u] + w

                # то есть для конца лучшее расстояние будет w + last_weight
                if weight < dist[to]:
                    dist[to] = weight

            

    
    return dist


# в этом алгоритме проще всего работать со списком вершин

n, m = map(int, input().split())
graph = []

for i in range(m):
    line = input()

    if not line:
        break
    
    vertex = list(map(int, line.split()))
    graph.append(vertex)

print('graph - ', graph)

# кол-во вершин - 1
print(belman_ford(graph, 0, n))

```
