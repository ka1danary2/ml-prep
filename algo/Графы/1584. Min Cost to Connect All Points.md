Ссылка на задачу - https://leetcode.com/problems/min-cost-to-connect-all-points/description/

Мне дан массив точек который отражает коррдинаты некоторых точек на 2д плоскости, где points[i] = [x_i, y_j]

Вес пути от одной точке до другой равен манхетонскому расстоянию - сумме абсолютных разностей между двумя точками на сетке

То есть это `|x_i - x_j| + |y_i - y_j|`

Нужно вернуть минимальную стоимость, необходимую для соединения всех точек и все точки соединены если между двумя любыми точками существует ровно один простой путь

Короче в задаче надо построить минимальное остовное дерево
И надо вернуть его стоимость

Мне кажется, что в этой задаче соседями могут быть любые точки, и мы по факту будем смотреть на наименьшее расстояние по манхетонскому расстоянию

Алгорим прима поможет построить минимальное остовное дерево

Ну и все, просто по алгоритму Прима действуем

Мое решение

```python
import heapq

class Solution:
    def minCostConnectPoints(self, points: List[List[int]]) -> int:
        dist = {}
        q = []
        answ = 0
        heapq.heapify(q)

        print(q)

        visited = {}

        for x, y in points:
            dist[(x, y)] = float('inf')
        
        for x, y in points:
            visited[(x, y)] = 0

        print(visited)
        print(dist)


        heapq.heappush(q, (0, *points[0]))

        while q:
            w, x, y = heapq.heappop(q)

            if visited[(x, y)] == 1:
                continue

            visited[(x, y)] = 1
            answ += w


            for a, b in points:
                

                if x == a and y == b:
                    continue

                mlen = abs(x - a) + abs(y - b)

                

                if mlen < dist[(a, b)]:
                    dist[(a, b)] = mlen
                    heapq.heappush(q, (mlen, a, b))

        return answ
```
