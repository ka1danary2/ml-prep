## ORDER BY
Сортировка для оператора SELECT

```sql
SELECT поля_таблиц FROM имя_таблиц
[WHERE условие]
ORDER BY столбец [ASC | DESC], [, ...];
```

Название компаний в алфавитном порядке

```sql
SELECT name FROM Company ORDER BY name;
```

Сортирвки для основных типов
- Строковые - по алфавиту
- Числа - от меньшего к большему
- Дата и время - от ранней даты к поздней
- Булевый тип - false идет перед true
- NULL значения - NULL идут первыми

Сортировка по нескольким столбцам
```sql
ORDER BY столбец_1 [ASC | DESC], столбец_2 [ASC | DESC], ...
```

Если при сортировке по первому столбцу данные совпадают, то они сортируются по второму столбцу и так далее

Выведем информацию о полетах, отсортированную по городу вылета самолета в пордке возрастания и по городу прибытия в порядке убывания

```sql
SELECT DISTINCT town_from, town_to FROM Trip
ORDER BY town_from, town_to DESC;
```
