**Краткое описание алгоритма:**
Алгорим нужен для поиска кратчайших путей между всеми парами вершин, работает с отрицательными весами

<mark style="background:#d2cbff"> O(v^3)</mark>

Структуры
- Граф - матрица смежностей
- Итоговая матрица - inf

Инициализация:
- Начальная матрица заполняется следующим образом
	- Если между ребрами нет связи, ставим inf
	- Если между ребрами есть связь, ставим вес
	- Если это ребро в само себя (например, диагональ), ставим либо 0, либо если есть петля с отрицательным весом, то ставим ее вес

Алгоритм:
- Перебор по номерам промежуточных вершин
	- Перебор вершин (откуда)
		- Перебор вершин (куда)
			- Рассматриваем путь через промежуточную вершину
			- Если путь через промежуточную вершину меньше, чем имеющийся, то обновляем его
Вывод матрицы

Код очень простой, работает алгоритм за o()v^3

Мой реализация 
```python

def floid(matrix: list, v: int):

    for i in range(v): # промежуточная вершина
        for a in range(v): # откуда
            for b in range(v): # куда
                current = matrix[a][b]
                newValue = matrix[a][i] + matrix[i][b]

                matrix[a][b] = min(current, newValue)

    return matrix

v, e = map(int, input().split())

max_item = float('inf')

# изначально матрицу заполняем бесконечностями
matrix = [[max_item] * v for _ in range(v) ]

# print('matrix', matrix)

for i in range(e):
    line = input()

    a, b, weight = map(int, line.split())

    matrix[a][b] = weight


for i in range(v):
    matrix[i][i] = 0

   
print('matrix', matrix)
print('new matrix', floid(matrix, v))
```
