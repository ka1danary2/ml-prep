# Менеджер памяти ()

#### Условия структуры данных
Нужно придумать свою структуру памяти.
Допустим, у нас есть старые огромные компы и у нас есть условия:
![[Pasted image 20260501101743.png]]

1. Есть неизвестное кол-во структур с двумя ссылками на другие две структуры (левый и правый потомок)
	Это есть выделенная память и объект с ключом и двумя ссылками на такие же объекты, можно визуализировать следующим образом:

![[Pasted image 20260501102118.png]]

Заранее (из условия) мы не знаем, сколько у нас элементов в структуре.

Но, мы знаем, какое максимальное кол-во структур может существовать одновременно
Мы хотим научиться выделять и освобождать память, то есть. стуктура должна поддерживать две операции.
#### Состояние после инициализации
Так выглдяит дерево до инициализации
Каждый элемент в левом сыне хранит ссылку на следующий элемент в ячейке памяти. Пока дерево пустое.

![[Pasted image 20260501102311.png]]
#### Как выделять память

Переход нужно сдлеать таким образом, чтобы первый свободный элемент показывал действительно на первый свободный. То есть надо выделить память на первый элемент

![[Pasted image 20260501102752.png]]
![[Pasted image 20260501102822.png]]

Ну и так далее, мы выделяем память, кладем туда какое-то осмысленное значение и ссылка на первый свободный элемент сдвигается дальше (как видно из картинки)
#### Как освободить память
Последний элемент искать долго, так как для этого надо обойти все дерево
Поэтому проще удалить первй элемент в дереве и на его место добавить новый 

![[Pasted image 20260501103207.png]]

Потом левого сына ставим на первого свободного элемента и получаем корректный односвязный список

![[Pasted image 20260501103326.png]]
### Код для менеджера памяти

 ```python
 
# Заполнение массива для менеджера памяти
def initMemory(n: int):
    memory = []
    for index in range(n):
        # значение 0, правый сын тоже 0, пока объявляет только односвязный список на левого сына
        memory.append([0, index + 1, 0])
    # струтктура дерева и указатель на первый свободный
    return [memory, 0]

# Выделить память под нод
def newNode(memstruct):
    # Деструктуризация, вытаскиваем объект памяти и ссылку на его первый элемент
    memory, firstFree = memstruct

    # В первый свобоюный элемент заменяется на следующий элемент
    memstruct[1] = memory[firstFree][1]

    # Это ссылка на вставленноый элемент
    return firstFree

# Очистить память под ноду
def delNode(memstruct, index):
    # Деструктуризация
    memory, firstFree = memstruct

    # Надо удалить, заменяет ссылку следующего на первый свободный элемент
    memory[index][1] = firstFree

    # Созраняем ссылка на новый первый свободный
    memstruct[1] = index
 ```

# Бинарное дерево поиска
- У каждого узла ключ и два потомка - левый и правый (максимум  2)

- В левом поддереве ключи меньше, а в правом - больше

- Если ключи поступают в случайном порядке, то глубина дерева будет `O(log n)` и дерево скорее всего будет заполенно полностью - то есть у предка будет по два сына
	Лист - это узел у которого нет потомка

![[Pasted image 20260501105706.png]]

##  Свойства бинарных деревьев
1. Из одних и тех же элементов можно составить разные бинарные деревья, это зависит от того, в каком порядке мы добавляем или обрабатываем элементы
![[Pasted image 20260501105809.png]]

Главная прелесть бин деревьев - мы можем любое поддерево обрабатывать как отдельное дерево с помощью рекусии.

2. Поддерево точно такое же дерево и обладает всеми таким же свойствами

### Реализация  бинарного дерева поиска элементов ( O(n)) в худшем случае

```python
def find(memstruct, root, x):
    # первый свободный memstruct[0] - это память
    # определеям ключ (значение, число в корне), который записан в корне дерева
    key = memstruct[0][root][0]

    # если искомый элемент совпал с значением в корне, то возвращаем его
    if x == key:
        return root
    
    # если ключ меньше корня, то идем налево
    elif x < key:
        # определяем кто левый ребенок
        left = memstruct[0][root][1]

        # если узла нет, то говорим что ничего не нашлось
        if left == -1:
            return - 1
        
        # иначе запускаем функцию рекурсивно по левому поддереву
        else:
            return find(memstruct, left, x)
    # если ключ больше корня, то идем направо и все действия аналогично левому поддереву
    elif x > key:
        right = memstruct[0][root][2]
        if right == - 1:
            return -1
        else:
            return find(memstruct, right, x)
```
