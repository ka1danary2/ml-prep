## LIMIT
Позволяет выбрать определенный диапазон записей на одной или нескольких таблицах

Синтаксис
```sql
SELECT поля_таблиц
FROM имя_таблицы
LIMIT [число_пропущенных,] число_строк;
```

Синтаксис с offset
```sql
SELECT поля_таблиц
FROM имя_таблицы
LIMIT число_строк [OFFSET число_пропущенных];
```
