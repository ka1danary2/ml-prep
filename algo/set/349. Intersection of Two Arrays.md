Тут главная загвоздка в том, что обычный цикл `for index in range(len(nums1))` не получится использовать, потому что класс `set` не позволяет обращаться к свои элементам по индексу, соответственно, мы не сможем в итоговый массив добавить элемент

А решение очень простое:
1. Создаем два списка `set`
2. Пробегаемся ПО ЭЛЕМЕНТАМ ПЕРВОГО СПИСКА
3. Если первый элемент есть во втором, то добавляем в ответ
4. Возвращаем ответ

```python
class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        set_a = set(nums1)
        set_b = set(nums2)
        answ = []

        for el in set_a:
            if el in set_b:
                answ.append(el)
    
        return answ
```
