## Группировка, GROUP BY

 ```sql
 SELECT {литерал | агрегатная_функция | поле_группировки } [, ...]
 FROM имя_таблицы
 GROUP BY поле_группировки [, ...]
 ```

Сгруппируем по типу жилья

```sql
SELECT home_type FROM Rooms
GROUP BY home_type
```

NULL значения интерпретируются как равные друг другу

Так как при работе с этим оператором мы перешли на работу с группами, а не с отедльными полями, мы не можем вывести любое поле из записи, то есть можно вывести только то, что определно однозначно после группировки:
- это поле группировки
- литерал
- агрегатную функцию

Теперь посчитаем среднюю цену с помощью группировки

```sql
SELECT home_type, AVG(price) FROM Rooms
GROUP BY home_type
```

Если нам надо добавить более детальную группировку по еще одному полю, то в Group by можно добавлять несколько полей для группировок


```sql
SELECT home_type, AVG(price) FROM Rooms
GROUP BY home_type, has_tv
```
