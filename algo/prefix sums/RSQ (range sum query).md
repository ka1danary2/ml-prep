Основная идея заключается в том, что мы:
- Создаем массив префиксов размером на 1 больше исходного
- Считаем массив префиксных сумм для исходного массива, складывая предыдущий элемент массива с предыдущим элементом исходного массива

```python
def makePrefixSum(nums):
	# создание массива префиксов с длиной на 1 больше длины исходного массива
	prefixSum = [0] * (len(nums) + 1) 
	
	for i in range(len(nums)):
		prefixSum[i + 1] = prefixSum[i] + nums[i]
	
	return prefixSum
	
def rsq(prefixSum, l, r):
	return prefixSum[r] - prefixSum[l]
```

Если мы пишем на питоне, но при этом у нас не проходит программа по времени - можно попробовать вызывать не функцию, а префиксные суммы, это будет немного быстрее
