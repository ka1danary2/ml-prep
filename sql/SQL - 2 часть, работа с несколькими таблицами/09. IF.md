## IF - для пары случаев проверок, типа тернарник

```sql
IF(условие, значение_1, значениу_2)
```

```sql
SELECT price,
IF(price >= 150, 'Комфорт-класс', 'Эконом-класс') as Category
FROM Room
```

Можно сделать вложенные if
```sql
SELECT price,
IF(price >= 150, 'Люкс-класс', IF(price >= 100, 'Бизнес-класс', 'Эконом-класс')) as Category
FROM Room
```

Вложенность это плохо, если больше 2х вариантов, луше вернуться к CASE

Функции для проверок
1) ?

```sql
IFNULL(значение, альтернатива)
```

2)  Если одинаковые, то NULL, иначе первая строка вернется
```sql
NULLIFF(значение_1, значение_2)
```

Пример 
```sql
SELECT id,  IF(has_tv, 'YES', 'NO') as has_tv FROM Rooms
```

Еще пример
```sql
SELECT first_name, IFNULL(middle_name,'Empty') as middle_name, last_name
FROM Teacher
```
