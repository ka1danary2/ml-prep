Что надо запомнить:

Запомнить то, как надо брать центральный элемент чтобы избежать проблем с округлением:

```python
mid = left + (right - left) // 2
```

Проверяем пока массив не станет равен 1 элементу, то есть левый край массива и правый не станут равны

Если элемент не найден, то сдвигаем край на 1 от среднего элемента 

## Решение 

 ```python
 class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left = 0
        right = len(nums) - 1

        while(left <= right):
            # Это делается чтобы избежать остатка при делении
            mid = left + (right - left) // 2

            if(target < nums[mid]):
                right = mid - 1
                continue

            if(target > nums[mid]):
                left = mid + 1
                continue

            return mid
        
        return -1
 
 ```
