Задача на ленивый указатель, когда один указатель ходит по массиву и смотрит цифры, второй их лишь записывает

В этой задаче довольно интересные условия вывода, в тестах есть скрипт который исходный массив смотрит на наличие уникальных отсортированных элементов до числа k, которое являестя количеством укникальных значений и до которого числа робот будет смотреть исходный массив. Поэтому жлементы надо перезаписывать в исходном массиве

```python
class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        pointer1 = 0
        pointer2 = pointer1 + 1
        k = 1
        while(pointer2 < len(nums)):
            if(nums[pointer1] == nums[pointer2]):
                pointer2 += 1
                continue
            nums[pointer1+1] = nums[pointer2]
            pointer1 += 1
            pointer2 += 1
            k += 1
        return k
```
