### Решение

Это задача почти задача [[RSQ (range sum query)]]

Отличается она запрашиваемыми интервалами, да и все 

Решение:
- Заполняем массив префиксов нулям
- Потом считаем префиксыные суммы - прошлую сумму складываем с текущим элементов массива
- Запрашиваем сумму в промежутке от права до лева (разность)

#### Код

```Python
class NumArray:
    def __init__(self, nums: List[int]):
        self.prefixSum = [0] * (len(nums) + 1)

        for i in range(len(nums)):
            self.prefixSum[i + 1] = self.prefixSum[i] + nums[i]


    def sumRange(self, left: int, right: int) -> int:
        return self.prefixSum[right + 1] - self.prefixSum[left]
```
