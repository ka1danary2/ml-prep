## SELECT 
Оператор может выбирать данные не толкьо из таблиц и структур, но и из строки

```sql
SELECT 'Hello world'
```

Выбор всех данных из таблицы

```sql
SELECT *
FROM TableNme
```

Вывод данных из опередленных атрибутов таблицы

```sql
SELECT member_id, member_name FROM FamilyMembers
```

Псевдонимы (до 255 знаков)

```sql
SELECT member_id, member_name AS Name 
FROM TableName
```
