ЧТобы не уйти в вечный цикл
- Будет продолжать поиск до двух элементов (while (l + 1 < r)) 
- На каждой итерации указатель l и r будем перемещать на m, без +1 или -1

В конце могут поджидать кучи проверок, и чтобы их изебежать
- если выполнять поиск не в отрезке l r, а в интервале (l, r), то в конце r будет указывать либо на первый элемент >= targetValue либо за конец массива, то есть в таком случае можно возвращать только r так как он будет укзаывать на нужный первый элемент

эту дичь можно еще попробовать вот так решить

```python
def find_first_occurrence(nums, target):
    l, r = 0, len(nums) - 1
    result = -1  # Запоминаем последнее найденное положение
    
    while l <= r:
        mid = (l + r) // 2
        
        if nums[mid] == target:
            result = mid  # Запоминаем позицию
            r = mid - 1   # Но продолжаем искать ЛЕВЕЕ (может быть раньше)
        elif target > nums[mid]:
            l = mid + 1
        else:
            r = mid - 1
    
    return result
```
