## Перевод задачки

Имея отсортированный массив различных целых чисел и целевое значение, верните индекс, если целевое значение найдено. В противном случае верните индекс, по которому оно находилось бы, если бы было вставлено в порядке возрастания.

Вам необходимо написать алгоритм с  `O(log n)`заданной временной сложностью.
## Решение и разбор

Может быть три случая:
- target < значения на mid
- target > значения на mid
-  target = значению на mid (сработает если target уже есть в массиве)

![[Pasted image 20260426205751.png]]

Рассмотрим прмер, на котором будет лучше понятно ход мыслей:

Пусть дан массив [2, 4, 6, 7, 7, 10] target = 3

1:
mid = значение 7
target < 7 -> обрезаем правую часть массива и сам элемент тоже (так как он больше и на его место вставить не получится)

массив после итерации:
[2, 4, 6]

2:
mid = значение 4
target < 4 -> обрезаем правую часть массива и сам элемент тоже (так как он больше и на его место вставить не получится)

массив после итерации:
[2]

3:
mid = значение 2
target > 2 -> на этом моменте и right и left равны

```python
class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        left = 0
        right = len(nums)

        while left < right:
            mid = left + (right - left) // 2

            if target > nums[mid]:
                left = mid + 1

            elif target < nums[mid]:
                right = mid
            
            else:
                return mid
        
        return left
            
```
