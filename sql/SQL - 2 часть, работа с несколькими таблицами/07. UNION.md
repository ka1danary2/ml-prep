## UNION
Оператор объединения нескольких атрибутов в один, берет результаты двух запросов, ставит один под другой

Синтаксис простой

```sql
SELECT town_from FROM Trip
UNION
SELECT town_to FROM Trip;
```

Если есть дубликаты, то он их уберет
### UNION ALL

Тоже самое, но с повторами
```sql
SELECT town_from FROM Trip
UNION ALL
SELECT town_to FROM Trip;
```

Работает быстрее так как нет проверок

Правила совместимости
- число столбцов
- типы совместимы (не одинаковые, только приводимые)
- порядок столбцов важе

UNION это не join

JOIN 
- соединяет по ширине, то есть сбоку
- должен быть ключ соединения

UNION
- соединяет по высоте, то есть ставит ниже
- не нужен ключ

### INTERSECT
Оставит только то, что есть в обоих столбцах

```sql
SELECT town_from FROM Trip
INTERSECT
SELECT town_to FROM Trip;
```

#### EXEPT
Вычитание - первый список - второй

```sql
SELECT town_from FROM Trip
EXCEPT
SELECT town_to FROM Trip;
```

Еще пример запроса
```sql
SELECT first_name, middle_name, last_name FROM Student
UNION ALL 
SELECT first_name, middle_name, last_name FROM Teacher
```
