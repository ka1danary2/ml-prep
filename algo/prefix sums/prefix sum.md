Префиксная сумма подходит для решения таких задач:
- Чему равна сумма элементов на полуинтервале от [L, R) от 1 до n -1 

![[Pasted image 20260413105248.png]]

Префиксная сумма подразумевает наличие 0 элемента в массиве, потому что сумма может быть равна и 0

### Построение массива префиксных сумм
Массив префиксных сумм можно построить за $O(n)$ 

$prefixSum = prefixSum[i - 1] + array[i - 1]$

Массив префиксных сумм всегда больше исходного массива на 1, так как хранит 1 элемент = 0

Нужно помнить о возможности переполнения префиксной суммы, то есть `long long + long long` = выход за пределы
