## HAVING

У нас есть запрос
```sql
SELECT home_type, AVG(price) as avg_price FROM Rooms
GROUP BY home_type
```

Надо доработать этот запрос так, чтобы в итоговой выборке отражались только те группы, чья средняя стоимость больше 50

Оператор WHERE использовать тут нельзя, так как для фильтрации групп используется оператор HAVING

Это из-за порядка выполнения sql запросов

FROM -> WHERE -> GROUP BY -> HAVING ->ORDER BY

Получается поле avg_price на момент проверки условия в WHERE еще не существовало

```sql
SELECT home_type, AVG(price) as avg_price FROM Rooms
GROUP BY home_type
HAVING avg_price > 50
```
