Решение получилось не через скользящее окно, а просто через жадник с указателями и простым запоминанием минимума, работает за O(n) так что по времени валидно

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        left = 0 
        answer = 0

        min_price = prices[0]

        if len(prices) > 1:
            max_price = prices[1]
        else:
            return answer

        for right in range(0, len(prices)):

            if prices[right] < min_price:
                min_price = prices[right]

                left = right
                continue
            
            if prices[right] > max_price:
                max_price = prices[right]

            answer = max(answer, prices[right] - prices[left])

        return answer

```

Но эталонным решением является решение через скользяшее окно, тут в целом два указателя не нужны, потому что минимум и максимум и так являются указателями

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        min_price = float('inf')
        max_profit = 0
        
        for price in prices:
            min_price = min(min_price, price)
            max_profit = max(max_profit, price - min_price)
        
        return max_profit
```
