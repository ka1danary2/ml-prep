## WHERE
Оператор условия для выборки в SELECT
Ну то есть это просто условный оператор

Структура запроса будет следующей

```sql
SELECT [DISTINCT] поля_таблиц
FROM имя_таблицы
WHERE условие [логический оператор условие] [...]; 
```

Пример запроса

```sql
SELECT * FROM Student
WHERE first_name = 'Grigory' AND YEAR(birthday) > 2000;
```

Результат сравнения может быть
- True
- False
- Null (если сравнивать в NULL)

Операторы сравнения
- =
- <=> Эквивалентность - как и равно но при NULL <=> NULL выдаст True,  и 0 при сравнении чего угодно с NULL
- <> !=
- <
- >
- <=
- >=

Логические операторы (в порядке приоритета выполнения)
- NOT
- AND
- XOR
- OR

Можно использовать () для определения иного приоритета

Простая фильтрация по числам
