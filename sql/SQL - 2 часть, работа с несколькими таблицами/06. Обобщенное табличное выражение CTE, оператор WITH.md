## Обобщенное табличное выражение CTE, оператор WITH

Временный результатирующий набор данных, к которому можно обращаться в последующих запросах (CTE)

Объявляется через оператор WITH

Живет во время выполнения одного запроса, то есть на время выполнения по месту использования

Нужен для того чтобы не загрязнять запросы и код был почище, чаще всего используется в связке с подзапросами, чтобы не писать их в основном запросе а вынести в красивый алиас

Общая структура

```sql
WITH название_cte [(столбец [, ...])] AS (подзапрос)
    [, название_cte [(столбец [, ...])] AS (подзапрос)] ...
```

Пример определения нескольких выражений, можно и одно

```sql
WITH 
	Aeroflot_trips AS
		(SELECT TRIP.* FROM Company
			INNER JOIN Trip On Trip.company = Company.is WHERE name = 'Aeroflot'
		),
	Don_avia_trips AS 
		(SELECT TRIP.* FROM Company
			INNER JOIN Trip On Trip.company = Company.is WHERE name = 'Don_Avia'
		)
		
SELECT * FROM Don_avia_trips UNION SELECT * FROM Aeroflot_trips
```

### CTE RESURSIVE
В CTE можно также работать с рекурсией

Рекрсивное CTE состоит из двух частей, разделенных оператором UINION ALL
- Начальный набор данных, который не содержит рекурсивных ссылок
- Рекурсивная часть - запрос, который ссылается на CTE чтобы продолжить рекурсию

Общая структура

```sql
WITH RECURSICE название_cte [(столбец [, ...])] AS (
	-- Начальный набор данных
	SELECT выражение [, ...]
    FROM имя_таблицы
    [WHERE условие]
    
    UNION ALL
    
    -- Рекурсивная часть
    SELECT выражение [, ...]
    FROM название_cte
    INNER JOIN имя_таблицы ON условие_соединения
	WHERE условие]
)

SELECT * FROM название_cte;
```

Пример запроса - дана таблица с иерархией подчинения, первый человек самый главный и никому не подчиняется

Требуется найти всех подчиненных для id = 1, даже вложенных

Простым запросом такое не решить, потому что иерархия может быть вложенной

```sql
WITH RECURSIVE Subordinates AS (
    -- Начальный набор данных
    SELECT id, name, managerId
    FROM Employees
    WHERE managerId = 1

    UNION ALL

    -- Рекурсивная часть: подчинённые подчинённых
    SELECT e.id, e.name, e.managerId
    FROM Employees e
    INNER JOIN Subordinates s ON e.managerId = s.id
)

SELECT * FROM Subordinates;
```

Шаги выполнения рекурсивного CTE 
- Объявление начального набора данных - выбираеются все сотрудники у которых managerId = 1
- Рекурсия - для каждого сотруника выбранного в начальном наборе данных выбираются подчиненные где managerid = id 
- Объединение - разультат начального набора данных объединяется с помощью UNION ALL
- Процесс повторяется рекурсивно пока все не будет выбраны
