## CASE - условная логика

Ну типа свитч кейс

```sql
SELECT price,
CASE 
	WHERE price >= 150 THEN 'Дорого'
	WHERE price >= 100 THEN 'Средне'
	ELSE 'Дешево'
END AS tier -- имя столбца
FROM Rooms
```

CASE проверяется сверху вниз, то есть надо правильно условия раставлять, самые узкие выше, самые широкие ниже

Если условие не подошло, то вернет NULL

Если там поле которое можно через сравнение проверить, то можно написать только его без условия
