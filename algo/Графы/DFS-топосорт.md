Это классический дфс-топосорт

Сначала надо написать классическую версию dfs алгоритма
[[1 dfs (обойти все варианты)]]

После, добавить список с порядком и очередью вершин

Вершины будем добавлять с конца, так как при добавлении с начала может быть такая ситуация, что в начальную вершину ссылаются и другие вершины из-за чего можно перепутать порядок посещения вершин

В ответ можно добавить вершину только тогда, когда уже были обработаны все исходящие из нее ребра и в ответ уже добавлены все последующие этапы

Ну и надо массив потом развернуть либо же использовать дек и доставать из его переда элементы

На результат такого алгоритма не влияет то, от какой вершины был запущен алгоритм

Моя реализация алгоритма на python
```python
def dfs(graph, dist, start_vertex, order):

        dist[start_vertex] = 1

        for neibor in graph[start_vertex]:
            if dist[neibor]  != 1:
                print('start dfs for ', neibor)
                dfs(graph, dist, neibor, order)
        
        # добавляем в очередь только после того, как обошли всех соседей вершины
        order.append(start_vertex)


v, e = map(int, input().split())
graph = {i: [] for i in range(v)}
dist = {i : 0 for i in range(v)}
order = []

print(dist)

for _ in range(e):
    a, b = map(int, input().split())

    if a not in graph:
        graph[a] = []
    
    graph[a].append(b)

    # if b not in graph:
    #     graph[b] = []
    
    # graph[b].append(a)

print(graph)

# для графа с одной компонентой связности можно без цикла
dfs(graph, dist, 0, order)

# если в графе есть несколько компонент связности, то нужен цикл

for i in range(v):
     if dist[i] != 1:
          dfs(graph, dist, i, order)

# возврат ордера в обратном порядке это и есть топологический порядок
```
